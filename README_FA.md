# ذهن تریدر 2.5.3

نسخه ۲.۵.۳ بر پایه نسخه ۲.۵.۲ تأییدشده ساخته شده و فقط دو اصلاح محدود دارد: خوانایی تاریخ‌های تقویم و حرفه‌ای‌سازی خروجی چاپی/PDF.

## اصلاحات 2.5.3
- افزایش کنتراست و وضوح اعداد روزهای تقویم در تم تیره؛ رنگ‌های سود و زیان نیز از اعداد تاریخ تفکیک شده‌اند.
- بهبود خوانایی عنوان ماه و روزهای هفته؛ تم روشن نیز رنگ‌بندی متناسب خود را دارد.
- ارتقای قالب PDF به گزارش A4 حرفه‌ای با هدر برند، بازه گزارش، چهار کارت شاخص، نمودارهای سود تجمعی و نتیجه معاملات، تحلیل ساعت و استراتژی، جدول خواناتر و جمع‌بندی برجسته.
- هیچ تغییری در ورود Passkey، داشبورد، فرم معامله، منطق معاملات، ساختار داده، رمزگذاری محلی یا اتصال Google Sheets/MT5 اعمال نشده است.

## انتشار
فایل‌های لازم در ریشه GitHub Pages: `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`. فایل `app.js` آینه کد برای نگهداری است و جداگانه بارگذاری نمی‌شود.

## امنیت و پشتیبان
پیش از جایگزینی نسخه زنده، از داخل برنامه پشتیبان رمزگذاری‌شده بگیر. پوشه `google-apps-script/Code.gs` را در مخزن عمومی GitHub قرار نده. URL وب‌اپ و API Token را محرمانه نگه دار.

## محدودیت آزمون
آزمون‌های نحوی و ساختاری انجام شده‌اند؛ چاپ PDF باید در Chrome/Android و روی دستگاه واقعی نیز کنترل شود.
