# ذهن تریدر 2.5.0

نسخه فارسی و راست‌به‌چپ ژورنال معاملاتی «ذهن تریدر» با رابط کاربری سبز نئونی/سرمه‌ای، مدیریت روان‌شناسی، گزارش تحلیلی و اتصال خواندنی به Google Sheets/MT5.

## تغییرات رابط کاربری 2.5.0

- ظاهر صفحات مطابق طرح تأییدشده: زمینه سرمه‌ای عمیق، رنگ تأکیدی سبز نئونی، کارت‌های شیشه‌ای/گرادیانی، آیکون حلقه‌ای برند و دکمه‌های آبی/سبز.
- داشبورد واکنش‌گرا با کارت برجسته سود خالص، نرخ برد، Profit Factor، امید ریاضی و حداکثر افت سرمایه.
- نوار پایین موبایل به ترتیب راست‌به‌چپ: داشبورد، ژورنال، ثبت معامله، روان‌شناسی، گزارش‌ها.
- صفحه ورود: در صورت وجود Passkey ثبت‌شده روی همان دستگاه، ورود بیومتریک/قفل صفحه دستگاه مسیر اصلی است؛ ورود با رمز عبور همچنان گزینه جایگزین است.
- پیش‌نمایش گزارش A4 قبل از چاپ/ذخیره PDF اضافه شده است.
- آیکون PWA و آیکون مرورگر با نشان سبز حلقه‌ای هماهنگ شدند.

## قابلیت‌های عملیاتی حفظ‌شده

- فضای ذخیره‌سازی محلی رمزگذاری‌شده با AES-GCM و مشتق‌سازی کلید PBKDF2.
- ثبت دستی معاملات و ورود داده‌های معاملات از Google Sheets.
- همگام‌سازی خواندنی از Google Apps Script و ادغام معاملات با شناسه منبع برای جلوگیری از تکرار.
- تحلیل سود/زیان، نرخ برد، Profit Factor، امید ریاضی، افت سرمایه، عملکرد ساعتی و مقایسه استراتژی‌ها.
- تکمیل روان‌شناسی معاملات، آمادگی ذهنی، تمرین تنفس، قوانین شخصی و هشدارهای ریسک.
- تقویم شمسی، خروجی CSV، پشتیبان رمزگذاری‌شده و گزارش PDF.

## ورود با اثر انگشت / Passkey

1. ورود بیومتریک به HTTPS و پشتیبانی مرورگر و احرازگر دستگاه از WebAuthn و افزونه PRF نیاز دارد.
2. اگر هنوز فضای امن ساخته نشده، ابتدا رمز اصلی را تعیین کن؛ پس از ورود به برنامه، در «اتصال و تنظیمات» گزینه «فعال‌سازی اثر انگشت / Passkey» را اجرا کن.
3. پس از ثبت موفق Passkey، در ورودهای بعدی دکمه Passkey در اولویت قرار می‌گیرد. اثر انگشت/چهره/PIN دستگاه توسط سیستم‌عامل مدیریت می‌شود و داده بیومتریک به برنامه یا سرور ارسال نمی‌شود.
4. اگر دستگاه یا مرورگر PRF را پشتیبانی نکند، ورود با رمز عبور در دسترس می‌ماند.
5. Passkey به دستگاه/پروفایل مرورگر وابسته است و همراه فایل پشتیبان منتقل نمی‌شود؛ روی دستگاه دیگر باید جداگانه ثبت شود.

## انتشار روی GitHub Pages

برای مخزن `behnam67rr/journalnew1`:

1. پیش از جایگزینی فایل‌ها، از داخل برنامه پشتیبان رمزگذاری‌شده بگیر.
2. ZIP را استخراج کن و فایل‌های زیر را در ریشه مخزن جایگزین کن:
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon.svg`
   - `icon-192.png`
   - `icon-512.png`
   - `apple-touch-icon.png`
3. پوشه `google-apps-script` را در مخزن عمومی قرار نده؛ فایل `Code.gs` فقط در محیط Apps Script استفاده می‌شود.
4. Commit کن و منتظر موفقیت workflow مربوط به GitHub Pages بمان.
5. پس از انتشار، سایت را باز و Refresh کن. کش Service Worker به `2.5.0` ارتقا یافته است.

## حفاظت از داده و محدودیت‌ها

- شناسه‌های ذخیره‌سازی `zt2_auth_v1` و `zt2_vault_v1` حفظ شده‌اند تا داده‌های محلی نسخه قبل قابل استفاده بمانند.
- برای جلوگیری از حذف ژورنال، داده‌های سایت/Local Storage را پاک نکن. قبل از ارتقا پشتیبان بگیر.
- آدرس Apps Script و API Token را عمومی نکن.
- اتصال Google Sheets همچنان خواندنی است؛ این رابط داده‌ای در شیت نمی‌نویسد.
- هشدارهای ریسک داخل ژورنال هستند و جلوی اجرای سفارش در MT5 را نمی‌گیرند.
- خروجی PDF از موتور چاپ مرورگر استفاده می‌کند؛ در پنجره چاپ گزینه Save as PDF را انتخاب کن.

## گزارش آزمون

آزمون ایستا شامل بررسی نحوی JavaScript، اعتبار JSON مانیفست، نبود شناسه HTML تکراری، وجود شناسه‌های مورد استفاده در کنترل‌های جدید و اعتبار ساختار ZIP انجام شده است. نصب واقعی PWA، احراز هویت بیومتریک روی گوشی، چاپ PDF در Chrome موبایل و اتصال زنده Google Sheets باید پس از انتشار روی دستگاه کاربر تأیید شوند؛ این موارد از محیط ساخت قابل تأیید قطعی نیستند.
