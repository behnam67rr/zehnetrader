# ذهن تریدر 2.4.2

نسخه توسعه‌یافته ژورنال معاملاتی و مدیریت روان‌شناسی ترید با رابط فارسی و چیدمان راست‌به‌چپ.

## قابلیت‌های نسخه 2.4

- منوی موبایل پنج‌قسمتی با ترتیب راست‌به‌چپ: داشبورد، ژورنال، ثبت معامله، روان‌شناسی، گزارش‌ها.
- دکمه تنظیمات و همگام‌سازی در نوار بالای موبایل.
- پایش سود/زیان روزانه در برابر حد زیان روزانه قابل تنظیم.
- هشدار تعداد زیان‌های متوالی، معاملات تکمیل‌نشده روان‌شناسی و آمادگی پایین ذهنی.
- تقویم شمسی عملکرد روزانه بر اساس منطقه زمانی دستگاه.
- تحلیل عملکرد بر اساس ساعت معامله و استراتژی.
- ثبت نام استراتژی و ریسک اولیه دلاری در معاملات دستی.
- محاسبه R واقعی (سود/زیان نهایی تقسیم بر ریسک اولیه ثبت‌شده).
- چاپ گزارش و امکان انتخاب Save as PDF در پنجره چاپ مرورگر.
- حفظ فضای ذخیره‌سازی رمزگذاری‌شده قبلی و شناسه‌های محلی موجود.

## نکات تحلیلی مهم

1. حد زیان روزانه در شروع روی صفر است؛ صفر یعنی هشدار حد زیان غیرفعال است. مقدار دلخواه را از «اتصال و تنظیمات ← حد ریسک روزانه» وارد و ذخیره کن.
2. هشدارهای ریسک فقط درون ژورنال هستند و جلوی ارسال سفارش در MetaTrader 5 را نمی‌گیرند. برای محدودیت اجرایی باید منطق جداگانه در اکسپرت/ربات MT5 پیاده شود.
3. محاسبه R فقط برای معاملاتی انجام می‌شود که ریسک اولیه دلاری آن‌ها ثبت شده باشد. معاملات قبلی بدون این داده حذف یا دستکاری نمی‌شوند.
4. ساعت معاملات از `openTime` استفاده می‌کند؛ اگر زمان ورود در شیت نباشد، زمان بسته‌شدن به‌عنوان تقریب به کار می‌رود.
5. مقایسه استراتژی‌ها فقط وقتی معنادار است که نام استراتژی برای معاملات وارد شود. در داده‌های قدیمی بدون نام، «نامشخص» نشان داده می‌شود.
6. PDF از طریق قابلیت چاپ مرورگر ساخته می‌شود: گزارش‌ها ← «چاپ / ذخیره PDF» ← Save as PDF.
7. تقویم شمسی و ساعت‌ها بر اساس منطقه زمانی دستگاه نمایش داده می‌شوند.

## انتشار روی GitHub Pages

برای مخزن `behnam67rr/journalnew1`:

1. پیش از انتشار، از داخل برنامه یک «پشتیبان امن» رمزگذاری‌شده بگیر.
2. فایل‌های زیر را در ریشه Pages آپلود و جایگزین کن:
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `icon.svg`
   - `icon-192.png`
   - `icon-512.png`
   - `apple-touch-icon.png`
3. تغییرات را Commit کن و برای انتشار GitHub Pages صبر کن.
4. در Chrome سایت را باز کن. Service Worker نسخه 2.4.2 باید cache قبلی را جایگزین کند.
5. برای نصب PWA، از منوی Chrome گزینه Install app را بررسی کن.

**مهم:** داده‌های برنامه در حافظه محلی مرورگر ذخیره می‌شوند. برای رفع مشکلات نصب، داده‌های سایت یا Local Storage را پاک نکن؛ این کار می‌تواند ژورنال محلی را حذف کند. ابتدا پشتیبان بگیر.

## Google Apps Script

فایل `google-apps-script/Code.gs` فقط برای قرار دادن در ویرایشگر Google Apps Script است. آن را در مخزن عمومی GitHub قرار نده. این اسکریپت برای خواندن شیت Journal استفاده می‌شود و در این نسخه نوشتن/ویرایش شیت را انجام نمی‌دهد.

## نگهداری داده‌های نسخه‌های قبلی

شناسه‌های ذخیره‌سازی `zt2_auth_v1` و `zt2_vault_v1` حفظ شده‌اند. فیلدهای جدید (`strategy`, `riskAmount`, `dailyLossLimit`, `lossStreakLimit`) اختیاری‌اند و برای داده‌های قدیمی مقدار پیش‌فرض اعمال می‌شود. با وجود این، پیش از انتشار حتماً پشتیبان بگیر.

## محدودیت آزمون

کد JavaScript از نظر نحوی بررسی شده، شناسه‌های ثابت HTML تکراری یا مفقود ندارند و فایل Manifest معتبر JSON است. اتصال زنده به Google Sheets، نصب روی دستگاه واقعی و عملکرد بیومتریک در حساب/گوشی کاربر از این محیط قابل تأیید نیست و باید پس از انتشار آزمایش شود.
