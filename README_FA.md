# ذهن تریدر 2.5.1

نسخه بازبینی‌شده ژورنال معاملاتی با رابط فارسی و راست‌به‌چپ. فایل `index.html` نسخه مستقل برنامه است و کد اجرایی درون آن قرار دارد؛ `app.js` نسخه همسان همان کد برای نگهداری/ویرایش است و در HTML به‌صورت جداگانه بارگذاری نمی‌شود.

## تغییرات 2.5.1

- بازطراحی داشبورد و فرم ثبت معامله بر اساس مرجع تأییدشده.
- نمایش تعداد معاملات در داشبورد.
- اصلاح برچسب وضعیت سود/زیان؛ دیگر نرخ برد به‌اشتباه به‌عنوان رشد سرمایه نمایش داده نمی‌شود.
- اصلاح برچسب «ورود با رمز عبور»؛ برنامه فضای محلی تک‌کاربره است و قابلیت تعویض حساب مستقل ندارد.
- به‌روزرسانی نسخه و نام کش PWA به `zehn-trader-2.5.1`.

## قابلیت‌ها

- ژورنال دستی و دریافت معاملات بسته‌شده از Google Sheets متصل به MT5.
- جلوگیری از ثبت تکراری با Ticket/Deal ID در صورت وجود شناسه یکتا.
- ثبت و تحلیل روان‌شناسی معاملات، قوانین شخصی و قفل وقفه.
- پایش زیان روزانه، زیان‌های متوالی و آمادگی ذهنی.
- تقویم شمسی، تحلیل ساعت ورود و مقایسه استراتژی‌ها.
- محاسبه R برای معاملات دارای ریسک اولیه دلاری.
- خروجی CSV و چاپ گزارش / Save as PDF.
- ذخیره محلی رمزگذاری‌شده با PBKDF2 (250,000 دور) و AES-GCM-256.
- پشتیبان‌گیری و بازیابی فایل پشتیبان رمزگذاری‌شده.
- پشتیبانی از Passkey در مرورگر و دستگاه سازگار.

## انتشار روی GitHub Pages

مخزن هدف درج‌شده در راهنمای انتشار: `behnam67rr/journalnew1`. پیش از جایگزینی فایل‌ها، از داخل برنامه پشتیبان رمزگذاری‌شده بگیر. سپس فایل‌های ریشه زیر را در ریشه Pages قرار بده:

- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `icon.svg`
- `icon-192.png`
- `icon-512.png`
- `apple-touch-icon.png`

فایل `google-apps-script/Code.gs` را در مخزن عمومی GitHub قرار نده؛ آن را فقط در پروژه خصوصی Google Apps Script استفاده کن. `README_FA.md`, `DEPLOY_FA.md`, `TEST_REPORT_FA.md`, `CHANGELOG_FA.md`, `VERSION.txt` و `app.js` فایل‌های همراه/توسعه‌اند و برای انتشار ریشه Pages ضروری نیستند.

## هشدارهای مهم

- داده‌ها روی همان مرورگر/دستگاه ذخیره می‌شوند؛ پاک‌کردن داده‌های سایت یا Local Storage می‌تواند ژورنال را از بین ببرد.
- پشتیبان رمزگذاری‌شده را در محل امن و جداگانه نگهداری کن.
- URL وب‌اپ Apps Script و API Token را عمومی نکن.
- JSONP باعث می‌شود توکن در URL درخواست وب‌اپ قرار بگیرد؛ فقط از URL وب‌اپ متعلق به خودت و HTTPS استفاده کن و از ثبت/اشتراک‌گذاری URL کامل حاوی token خودداری کن.
- هشدارهای ریسک فقط درون ژورنال هستند و سفارش‌های MT5 را متوقف نمی‌کنند.
- Passkey فقط پس از ثبت آن روی همان دامنه/دستگاه و در بستر امن HTTPS قابل استفاده است.

## محدوده آزمون

آزمون‌های ایستا در گزارش کنترل فنی ثبت شده‌اند. اتصال زنده به Google Sheets، نصب PWA روی گوشی واقعی و ورود Passkey باید پس از انتشار در محیط واقعی کاربر آزموده شوند.
